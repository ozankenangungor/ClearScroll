ClearScroll help and privacy

Settings

Your controls

ClearScroll is optional, best-effort topic blurring for webpage text. Add a topic in Settings and save. Precise is more selective; Balanced covers more; Thorough may hide more unrelated text. English works best. Misses and incorrect hides are possible.

Click or keyboard-focus a blurred item and press Enter or Space to reveal it. A second click can follow its link. Use the toolbar popup to pause or resume filtering or exclude a site. In Settings, turn Filtering enabled off to restore normal browsing.

Nothing runs without an enabled topic. Page content may appear before the model loads or checks it. CPU fallback is automatic when a supported GPU is unavailable. If the semantic engine cannot start, status says keyword matching only; only literal topic matches are then checked. Pause to stop all filtering.

Supported scope

This release filters text, not image pixels, audio or video. A matching text card can also blur its thumbnail. It is not a guaranteed spoiler blocker, parental control or complete harmful-content protection system.

YouTube video and Shorts filtering is unsupported. Hover previews may escape the blur. New installs visibly exclude youtube.com and youtu.be; removing those rules enables experimental behavior. Updates retain existing site choices. Chrome pages, Web Store pages, PDFs and embedded frames are unsupported. Reload pages after disabling, removing or updating the extension if old styles remain.

Privacy

Text inference and models run on this device. ClearScroll has no telemetry, accounts, external AI service or text-release media-download feature. It does not upload page text, browsing addresses or feedback. Ordinary websites and Chrome can still make their own requests.

Enabled webpages supply eligible text to a shared local extension worker in memory. Forms and editable areas are protected; detection is not a guarantee that every private-looking webpage area is recognized. Exclude sensitive sites when desired. Bounded text and embedding caches are temporary and clear when filtering is paused or the engine is closed.

Settings (topics, exclusions and preferences) persist in Chrome local extension storage. Local feedback stores your selected topic and limited item metadata, never page text, page URLs or input credentials. At most 100 reports are retained, for up to 30 days, pruned on subsequent activity. Optional diagnostic fields are added only with your consent.

Delete all local feedback in Settings. Export downloads a JSON file for your review; topic names may be personal. Deletion in the extension does not delete previously exported files. Copied diagnostics omit page content, addresses and raw errors; topic names are opt-in. Uninstall removes Chrome's local extension storage. Remove exported files yourself if no longer wanted.

This policy describes the text-focused release. Private 0.3.5 had a separate experimental image feature with explicit media-download consent; it is not included here.

Getting help

Use the ClearScroll GitHub repository's Issues page for support. Describe the problem, Chrome version, operating system and mode. Share only public reproduction examples you have checked for private information. Feedback remains local until you choose to share an export. No issue or export is sent automatically.
