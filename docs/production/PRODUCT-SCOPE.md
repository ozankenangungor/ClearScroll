# ClearScroll: supported product

ClearScroll is an optional, local-first, AI-assisted Chrome extension that blurs webpage text related to topics the user selects. Filtering is best-effort. It can miss related content and hide unrelated content. It is not a guaranteed spoiler blocker, parental-control security product, complete harmful-content protection system or perfect semantic classifier.

The first public package is text-focused: semantic English text filtering, Precise/Balanced/Thorough modes, reveal, pause/resume, site exclusions, per-topic literal exclusions, local feedback with export/deletion, local inference, CPU fallback, supported nonfallback WebGPU and persistent settings. Existing text-based card ownership can blur a card and its thumbnail; that is not image classification.

No topics are preconfigured. New installs visibly exclude youtube.com and youtu.be using ordinary editable rules. YouTube video/Shorts filtering is unsupported because previews may escape blurring. Removing those rules enables experimental behavior. Updates/migrations retain existing site choices and must consult the limitation notice.

Image pixel classification, optional image downloads, audio/video understanding and automatic spoiler recognition are omitted. Chrome/Web Store/restricted pages, PDFs, embedded frames and private shadow roots are unsupported. Short headings, ambiguous senses, long-text truncation and dynamic site layouts can cause misses or incorrect hides. Existing correlated AI development examples are regression evidence, not population accuracy or independent human validation.
