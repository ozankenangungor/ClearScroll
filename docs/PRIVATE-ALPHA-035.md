# ClearScroll 0.3.5 private alpha

Use the separate **ClearScroll 0.3.5 Private Alpha** application-menu launcher.
It uses its own Chrome Stable profile. Choose topics in Settings; the launcher
preconfigures no topics or exclusions. Images and other-domain picture downloads
remain off by default. Feedback stays local and can be exported or deleted.

Version 0.3.5 contains the verified Phase 5B removal/movement cleanup: a card no
longer keeps a removed matching text unit's obsolete blur. Reinserted units are
rechecked; same-card reordering preserves the existing verdict. Classifiers,
models, thresholds, scope controls and permissions are unchanged.

The **ClearScroll 0.3.4 Private Alpha** launcher and profile remain separate and
available for rollback. Neither alpha changes your normal browser profile or
default browser. The optional NVIDIA launcher action uses process-local settings;
close that alpha's window before switching modes.

This is a private alpha, not a relevance-accuracy guarantee. Existing sense,
short-heading, truncated long-text and context limitations remain. The measured
stress tests are bounded; they do not prove leak-free behavior for every website.
Full release-engineering evidence is under `build/alpha035-evidence/` on Oracle.
